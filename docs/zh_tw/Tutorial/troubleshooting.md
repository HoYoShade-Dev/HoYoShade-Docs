# 常見問題與疑難排解

本文彙整使用 HoYoShade 過程中的常見故障排查方法與診斷流程。

## 1. 注入器一直提示「等待遊戲啟動」，啟動遊戲後無反應

控制台視窗停留在 `Waiting for a '...' process to start ...`，在啟動器中打開遊戲後無任何輸出變化：

- **排查客戶端匹配**：檢查所選的客戶端與實際運行的遊戲是否一致。例如國服《原神》主程序為 `YuanShen.exe`，國際服為 `GenshinImpact.exe`。若在注入器中選錯渠道，注入器將無法監聽目標進程。詳細對照請參考 [判斷客戶端類型](/zh_tw/Tutorial/check-your-client)。
- **檢查執行權限**：若遊戲啟動器或遊戲主程序啟用了「以系統管理員身分執行」，而注入器以普通使用者權限運行，注入器將因權限不足無法掛載目標進程。嘗試右鍵點擊 HoYoShade 啟動器並選擇「以系統管理員身分執行」。
- **安全軟體背景攔截**：部分防護軟體會在不跳出提示的情況下攔截記憶體注入 API。請參考 [防毒軟體排除設定](/zh_tw/Tutorial/antivirus) 為相關目錄配置排除項。

## 2. 遊戲啟動後立即崩潰、閃退或彈出 D3D 錯誤

遊戲打開時瞬間閃退、黑屏關閉或提示 Direct3D 裝置丟失：

- **第三方遊戲覆疊衝突**：ReShade 需要接管 DirectX 的交換鏈與渲染調用。若背景同時存在其他掛鉤工具，極易發生介面競爭：
  - **RivaTuner Statistics Server (RTSS)**：將遊戲的 Application Detection Level 設為 `None`，或開啟 Custom Direct3D Support。
  - **GeForce Experience / NVIDIA App**：在設定中暫時關閉「遊戲內覆疊」。
  - **Discord / Steam / 遊戲加加**：關閉對應軟體的遊戲內懸浮窗與狀態監測覆疊。
- **顯示卡驅動異常**：過舊的顯示卡驅動可能缺少部分 DirectX 11/12 渲染擴展指令，建議更新至顯示卡廠商最新發布的穩定版驅動程式。
- **著色器檔案損壞**：若自行新增了外部著色器，語法錯誤可能導致編譯異常。可嘗試暫時清空自訂著色器，恢復為預設自帶的 `reshade-shaders`。

## 3. 進入遊戲後按 Home 鍵無法呼出配置選單

遊戲畫面正常渲染，但無法打開 ReShade 設定介面：

- **確認鍵盤組合鍵映射**：許多筆記型電腦或 87 鍵緊湊型鍵盤沒有獨立的 <kbd>Home</kbd> 實體按鍵，通常需要配合 <kbd>Fn</kbd> 鍵輸入（如 <kbd>Fn</kbd> + <kbd>Home</kbd> 或 <kbd>Fn</kbd> + <kbd>←</kbd>）。
- **確認 `ReShade.ini` 所在路徑**：`ReShade.ini` 必須放置在包含遊戲執行檔的目錄中，而非啟動器外層目錄。若該檔案未就位，ReShade 將無法讀取快捷鍵綁定。
- **自訂呼出快捷鍵**：若按鍵衝突，可在記事本中打開遊戲目錄下的 `ReShade.ini`，搜尋 `KeyOverlay=` 並將鍵碼更改為其他按鍵（例如將 `KeyOverlay=36,0,0,0` 改為其他鍵值）。

## 4. 遊戲版本更新後如何恢復使用？

米哈遊遊戲客戶端在常規熱更新或大版本換代後：

- 理論上 HoYoShade 無需等待重新適配，仍可直接注入。
- 若更新後無法呼出，請檢查遊戲目錄中的 `ReShade.ini` 是否在更新過程中被官方啟動器清理。若遺失，重新從 HoYoShade 目錄複製一份即可。

## 5. 景深 (DOF) 等深度緩衝區特效不生效

- 為防止線上多人網路遊戲中利用深度通道實現透視外掛，通用 ReShade 會在檢測到網路通訊或特定多玩家場景時關閉高精度深度緩衝區訪問。
- HoYoShade 附帶的調色預設主要基於色彩校正、曲度調光、色調映射（Tonemap）與銳化演算法，無需深度緩衝即可穩定生效。
