# 快速開始

歡迎查閱 HoYoShade 文檔。本頁提供核心概念說明與基礎上手流程，協助你了解並運行 HoYoShade。

## 什麼是 HoYoShade？

HoYoShade 是基於官方開源 ReShade 二次開發的圖形增強項目，專為 miHoYo / HoYoverse 旗下 PC 端遊戲客戶端定制。

ReShade 透過攔截 CPU 發往 GPU 的圖形 API 調用與通訊，在後處理階段調節與增強渲染畫面。HoYoShade 針對米哈遊旗下遊戲客戶端的環境特點做了適配：

- **統一注入方案**：搭載 ⌈幻港之蝶⌋ 自研注入內核，提供跨遊戲的適配能力，簡化繞過反作弊與手動掛載的流程。
- **抗版本更新**：注入機制基於通用進程空間加載，理論上在遊戲常規大版本更新與熱補丁後無需等待軟體適配，可直接繼續使用。
- **生態與模組相容**：針對常用的啟動器（如 HoYoPlay、Starward）及輔助工具（如 FPS 解鎖器、3DMigoto）保持良好的相容性，支援鏈式啟動。
- **開箱即用**：整合常用的遊戲專用著色器庫（Shaders）、本土化介面字體及預設配置（Presets）。
- **架構開源透明**：核心加載與注入邏輯完全開源，遵循 BSD-3 開源協議。

## 使用須知與安全規範

在使用前，請了解以下注意事項：

- **帳號與環境安全**：雖然 HoYoShade 僅修改遊戲本地後處理渲染畫面，不修改遊戲記憶體資料與邏輯數值，但官方反作弊系統隨時可能調整策略。使用任何第三方注入工具均存在潛在的封號或風控風險，使用責任由用戶個人承擔。建議了解 [使用者協議](/zh_tw/user-agreement)。
- **內容創作提示**：如需錄製影片、直播或公開發布遊戲畫面，建議關閉遊戲內 UID 顯示，並避免在公開串流媒體中直接展示模組注入配置介面。
- **非官方聲明**：本項目由社群獨立維護，與 miHoYo / HoYoverse 官方無隸屬或經濟關係。請勿向遊戲官方客服反饋任何由模組引起的故障。
- **開源免費**：HoYoShade 開源版本永久免費分發。若你在任何電商平台、二手交易平台或社群中付費購買了本開源包，請及時向交易平台申請退款並檢舉。

## 運行環境要求

- **作業系統**：Windows 10 或 Windows 11（64 位元系統）。不支援 macOS、Linux、HarmonyOS 及轉譯環境。
- **硬體配置**：
  - CPU 與記憶體：滿足目標遊戲客戶端的最低官方運行要求。
  - 顯示卡（GPU）：支援 DirectX 11 或 DirectX 12 介面。建議效能不低於 NVIDIA GeForce GTX 1060 / AMD Radeon RX 580，並安裝顯示卡廠商官方發布的最新穩定版驅動程式。
- **運行庫**：需安裝常見的 Microsoft Visual C++ 2015-2022 Redistributable（x64）。

## 三步上手流程

1. **準備與解壓縮**：
   從 [GitHub Releases](https://github.com/DuolaD/HoYoShade/releases) 下載最新版本的發行包，將其解壓縮至非系統根目錄（例如 `D:\HoYoShade\`）。在解壓縮前建議將該目錄新增至系統防毒軟體的信任清單，詳見 [防毒軟體排除設定](/zh_tw/Tutorial/antivirus)。

2. **啟動注入器並選擇客戶端**：
   運行 HoYoShade 啟動程式，在清單中選擇你正在運行的遊戲及客戶端版本（若不確定具體渠道，請先查閱 [判斷客戶端類型](/zh_tw/Tutorial/check-your-client)）。注入器會進入等待監聽狀態。

3. **啟動遊戲並載入預設**：
   透過官方啟動器或 Starward 啟動遊戲。遊戲加載後，畫面頂端會出現 ReShade 編譯提示條。進入遊戲後按下鍵盤的 <kbd>Home</kbd> 鍵即可呼出控制面板並選擇畫面預設。
