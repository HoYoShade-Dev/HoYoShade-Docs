# 防毒軟體排除設定

在使用各類注入式模組時，安全軟體的誤報與背景攔截是導致注入失敗最常見的原因。本指南說明誤報的成因以及如何在常見防毒軟體中正確新增排除項。

## 為什麼安全軟體會產生誤報？

HoYoShade 的底層注入內核（⌈幻港之蝶⌋）需要將圖形渲染模組 `ReShade64.dll` 掛載至遊戲進程中。此過程涉及 Windows 進程注入 API（如 `OpenProcess`、`VirtualAllocEx`、`WriteProcessMemory` 及 `CreateRemoteThread`）。

由於部分木馬與病毒程式同樣會採用進程注入手段，現代防毒軟體的啟發式行為分析與雲端查殺引擎常會將此類注入行為一律標記為「可疑注入工具」（如 `HackTool:Win32/Injector` 或 `Trojan:Win32/Wacatac`）。

HoYoShade 的全部注入源代碼已在官方倉庫開源（見 [`inject_mod.cpp`](https://github.com/DuolaD/HoYoShade/blob/V2.X.X-Stable/inject_mod.cpp)），不包含任何數據收集、後門或惡意破壞邏輯。為確保程式正常運作，建議在使用前將 HoYoShade 所在目錄加入防毒軟體排除名單。

## Windows 安全性中心 (Windows Defender) 設定步驟

若使用 Windows 10 或 Windows 11 內建的 Windows Defender：

1. 打開 Windows 開始功能表，搜尋並打開 **Windows 安全性中心**（Windows Security）。
2. 在左側或主介面中點擊 **病毒與威脅防護**。
3. 找到「“病毒與威脅防護”設定」區塊，點擊 **管理設定**。
4. 向下滾動頁面，找到「排除項目」區塊，點擊 **新增或移除排除項目**。
5. 系統快顯 UAC 提權提示時點擊「是」。
6. 點擊 **新增排除項目** 按鈕，在下拉選單中選擇 **資料夾**。
7. 瀏覽並選中解壓縮出的 HoYoShade 完整資料夾（例如 `D:\HoYoShade\`）。
8. *(可選建議)* 同樣以資料夾形式將包含遊戲主程序的安裝根目錄一併新增至排除項目中。

## 第三方防毒軟體設定建議

若設備安裝了第三方安全防護軟體（如火絨安全、360、卡巴斯基等）：

- **火絨安全**：打開主介面 -> 點擊右上角功能表 -> 設定 -> 病毒防護 -> 排除項管理 -> 新增資料夾，選擇 HoYoShade 目錄即可。
- **其他防毒軟體**：進入各軟體的「信任區」、「白名單」或「防護排除」設定中，將 HoYoShade 所在資料夾加入信任。

## 檔案被誤刪後的復原方法

如果在配置排除項之前壓縮包已解壓縮，且發現目錄中的執行檔或 `ReShade64.dll` 自動消失：

1. 打開防毒軟體的「隔離區」或「保護歷程記錄」。
2. 找到對應時間被隔離的 HoYoShade 檔案。
3. 點擊「還原」並勾選「同時加入信任清單」。
4. 若已被徹底清除，請先配置好排除項，再重新解壓縮下載的壓縮包。
