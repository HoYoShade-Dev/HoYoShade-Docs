# 使用官方啟動器 (HoYoPlay) 安裝與運行

本指南介紹如何在米哈遊官方啟動器（HoYoPlay）管理的遊戲客戶端中配合運行 HoYoShade。

## 準備工作

1. 確保遊戲本體已透過 HoYoPlay 完整下載且可正常獨立運行。
2. 確保在操作前遊戲進程已處於完全關閉狀態。
3. 從 Release 頁面下載最新的 HoYoShade 壓縮包並解壓縮至獨立目錄（如 `D:\HoYoShade\`）。
4. 為避免核心注入模組被系統誤報或攔截，建議先參考 [防毒軟體排除設定](/zh_hk/Tutorial/antivirus) 為 HoYoShade 目錄配置信任名單。

## 具體操作步驟

### 第一步：定位遊戲安裝根目錄

HoYoPlay 啟動器所在目錄與實際遊戲進程目錄屬於不同層級，需定位到遊戲主程序所在的文件目錄：

1. 打開 HoYoPlay 啟動器，並在左側或頂部標籤切換至目標遊戲（例如《原神》或《崩壞：星穹鐵道》）。
2. 點擊啟動器右下方「開始遊戲」按鈕旁的**更多選項圖示（三條橫線或齒輪）**，選擇**遊戲設定**。
3. 在「基本資訊」或「遊戲安裝位置」項後，點擊**打開所在目錄**。
4. 資源管理器將打開遊戲目錄，確認此目錄下存在對應的遊戲主程序（如 `YuanShen.exe`、`GenshinImpact.exe`、`StarRail.exe` 或 `ZenlessZoneZero.exe`）。

### 第二步：部署設定檔 `ReShade.ini`

1. 首次打開解壓縮後的 HoYoShade 資料夾，運行其中的 HoYoShade 啟動器（以對應語言命名的執行檔或腳本）。
2. 程式啟動後會在 HoYoShade 根目錄生成一份 `ReShade.ini` 設定檔。
3. 將此 `ReShade.ini` 複製並貼上到第一步中打開的**遊戲主程序根目錄**中。

> 提示：`ReShade.ini` 中定義了著色器檔案與預設檔案的絕對或相對索引路徑。放置到遊戲執行檔同級目錄後，遊戲進程啟動時即可被 ReShade 內核識別。後續日常遊玩無需重複複製。

### 第三步：運行注入器並監聽

1. 在 HoYoShade 啟動器中，根據你的遊戲和伺服器分區輸入對應的序號（若不確定，請參考 [判斷客戶端類型](/zh_hk/Tutorial/check-your-client)）。
2. 控制台視窗將顯示類似如下資訊並處於等待監聽狀態：
   ```text
   Waiting for a 'YuanShen.exe' process to start ...
   ```
3. 保持該控制台視窗在背景運行，切勿直接關閉。

### 第四步：從 HoYoPlay 啟動遊戲

1. 回到 HoYoPlay 官方啟動器，點擊**開始遊戲**。
2. 遊戲主程序被啟動後，HoYoShade 注入器會自動捕獲到遊戲進程 PID 並完成掛載，控制台輸出：
   ```text
   Found a matching process with PID 12345! Injecting HoYoShade ... Succeeded!
   ```
3. 注入完成後，控制台將自動結束或退出，不會額外常駐佔用系統資源。

### 第五步：遊戲內驗證與預設選擇

1. 進入遊戲加載介面，螢幕頂部會出現 ReShade 狀態列，顯示著色器與紋理載入進度。
2. 載入完成後，按下鍵盤上的 <kbd>Home</kbd> 鍵呼出配置介面。
3. 在面板頂部的預設下拉選單中，選擇隨包附帶的對應遊戲調色預設（如適用於原神、星穹鐵道或絕區零的色彩風格），或根據喜好自行微調各項特效。

## 遊戲版本更新後的處理

米哈遊官方客戶端在進行小版本熱更新或大版本換代時，通常會保留安裝目錄下的額外設定檔。更新完成後：

1. 確認遊戲主程序目錄中的 `ReShade.ini` 依然存在。
2. 在啟動遊戲前照常開啟 HoYoShade 注入器並等待遊戲啟動即可。
3. 若遇到啟動器全量重裝遊戲導致目錄變動，重新將 `ReShade.ini` 放置入新的主程序目錄即可恢復。
