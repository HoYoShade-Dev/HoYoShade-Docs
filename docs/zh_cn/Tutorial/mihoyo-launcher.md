# 使用官方启动器 (HoYoPlay) 安装与运行

本指南介绍如何在米哈游官方启动器（HoYoPlay）管理的游戏客户端中配合运行 HoYoShade。

## 准备工作

1. 确保游戏本体已通过 HoYoPlay 完整下载且可正常独立运行。
2. 确保在操作前游戏进程已处于完全关闭状态。
3. 从 Release 页面下载最新的 HoYoShade 压缩包并解压至独立目录（如 `D:\HoYoShade\`）。
4. 为避免核心注入模块被系统误报或拦截，建议先参考 [杀毒软件排除设置](/zh_cn/Tutorial/antivirus) 为 HoYoShade 目录配置白名单。

## 具体操作步骤

### 第一步：定位游戏安装根目录

HoYoPlay 启动器所在目录与实际游戏进程目录属于不同层级，需定位到游戏主程序所在的文件目录：

1. 打开 HoYoPlay 启动器，并在左侧或顶部标签切换至目标游戏（例如《原神》或《崩坏：星穹铁道》）。
2. 点击启动器右下方“开始游戏”按钮旁的**更多选项图标（三条横线或齿轮）**，选择**游戏设置**。
3. 在“基本信息”或“游戏安装位置”项后，点击**打开所在目录**。
4. 资源管理器将打开游戏目录，确认此目录下存在对应的游戏主程序（如 `YuanShen.exe`、`GenshinImpact.exe`、`StarRail.exe` 或 `ZenlessZoneZero.exe`）。

### 第二步：部署配置文件 `ReShade.ini`

1. 首次打开解压后的 HoYoShade 文件夹，运行其中的 HoYoShade 启动器（以对应语言命名的可执行文件或脚本）。
2. 程序启动后会在 HoYoShade 根目录生成一份 `ReShade.ini` 配置文件。
3. 将此 `ReShade.ini` 复制并粘贴到第一步中打开的**游戏主程序根目录**中。

> 提示：`ReShade.ini` 中定义了着色器文件与预设文件的绝对或相对索引路径。放置到游戏可执行文件同级目录后，游戏进程启动时即可被 ReShade 内核识别。后续日常游玩无需重复复制。

### 第三步：运行注入器并监听

1. 在 HoYoShade 启动器中，根据你的游戏和服务器分区输入对应的序号（若不确定，请参考 [判断客户端类型](/zh_cn/Tutorial/check-your-client)）。
2. 控制台窗口将显示类似如下信息并处于等待监听状态：
   ```text
   Waiting for a 'YuanShen.exe' process to start ...
   ```
3. 保持该控制台窗口在后台运行，切勿直接关闭。

### 第四步：从 HoYoPlay 启动游戏

1. 回到 HoYoPlay 官方启动器，点击**开始游戏**。
2. 游戏主程序被调起后，HoYoShade 注入器会自动捕获到游戏进程 PID 并完成挂载，控制台输出：
   ```text
   Found a matching process with PID 12345! Injecting HoYoShade ... Succeeded!
   ```
3. 注入完成后，控制台将自动结束或退出，不会额外常驻占用系统资源。

### 第五步：游戏内验证与预设选择

1. 进入游戏加载界面，屏幕顶部会出现 ReShade 状态栏，显示着色器与纹理载入进度。
2. 载入完成后，按下键盘上的 <kbd>Home</kbd> 键呼出配置界面。
3. 在面板顶部的预设下拉框中，选择随包附带的对应游戏调色预设（如适用于原神、星穹铁道或绝区零的色彩风格），或根据喜好自行微调各项特效。

## 游戏版本更新后的处理

米哈游官方客户端在进行小版本热更新或大版本换代时，通常会保留安装目录下的额外配置文件。更新完成后：

1. 确认游戏主程序目录中的 `ReShade.ini` 依然存在。
2. 在启动游戏前照常开启 HoYoShade 注入器并等待游戏启动即可。
3. 若遇到启动器全量重装游戏导致目录变动，重新将 `ReShade.ini` 放置入新的主程序目录即可恢复。
