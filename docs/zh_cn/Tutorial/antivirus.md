# 杀毒软件排除设置

在使用各类注入式模组时，安全软件的误报与静默拦截是导致注入失败最常见的原因。本指南说明误报的成因以及如何在常见杀毒软件中正确添加排除项。

## 为什么安全软件会产生误报？

HoYoShade 的底层注入内核（⌈幻港之蝶⌋）需要将图形渲染模块 `ReShade64.dll` 挂载至游戏进程中。此过程涉及 Windows 进程注入 API（如 `OpenProcess`、`VirtualAllocEx`、`WriteProcessMemory` 及 `CreateRemoteThread`）。

由于部分木马与病毒程序同样会采用进程注入手段，现代杀毒软件的启发式行为分析与云查杀引擎常会将此类注入行为一律标记为“可疑注入工具”（如 `HackTool:Win32/Injector` 或 `Trojan:Win32/Wacatac`）。

HoYoShade 的全部注入源码已在官方仓库开源（见 [`inject_mod.cpp`](https://github.com/DuolaD/HoYoShade/blob/V2.X.X-Stable/inject_mod.cpp)），不包含任何数据收集、后门或恶意破坏逻辑。为确保程序正常工作，建议在使用前将 HoYoShade 所在目录加入杀毒软件排除名单。

## Windows 安全中心 (Windows Defender) 设置步骤

若使用 Windows 10 或 Windows 11 自带的 Windows Defender：

1. 打开 Windows 开始菜单，搜索并打开 **Windows 安全中心**（Windows Security）。
2. 在左侧或主界面中点击 **病毒和威胁防护**。
3. 找到““病毒和威胁防护”设置”区块，点击 **管理设置**。
4. 向下滚动页面，找到“排除项”区块，点击 **添加或删除排除项**。
5. 系统弹出 UAC 提权提示时点击“是”。
6. 点击 **添加排除项** 按钮，在下拉列表中选择 **文件夹**。
7. 浏览并选中解压出的 HoYoShade 完整文件夹（例如 `D:\HoYoShade\`）。
8. *(可选推荐)* 同样以文件夹形式将包含游戏主程序的安装根目录一并添加到排除项中。

## 第三方杀毒软件设置建议

若设备安装了第三方安全防护软件（如火绒安全、360、卡巴斯基等）：

- **火绒安全**：打开主界面 -> 点击右上角菜单 -> 设置 -> 病毒防护 -> 排除项管理 -> 添加文件夹，选择 HoYoShade 目录即可。
- **其他杀毒软件**：进入各软件的“信任区”、“白名单”或“防护排除”设置中，将 HoYoShade 所在文件夹加入信任。

## 文件被误删后的恢复方法

如果在配置排除项之前压缩包已解压，且发现目录中的可执行文件或 `ReShade64.dll` 自动消失：

1. 打开杀毒软件的“隔离区”或“保护历史记录”。
2. 找到对应时间被隔离的 HoYoShade 文件。
3. 点击“还原”并勾选“同时加入信任列表”。
4. 若已被彻底清理，请先配置好排除项，再重新解压下载的压缩包。
