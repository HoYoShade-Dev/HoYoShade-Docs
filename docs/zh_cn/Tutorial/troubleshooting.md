# 常见问题与排错

本文汇总使用 HoYoShade 过程中的常见故障排查方法与诊断流程。

## 1. 注入器一直提示“等待游戏启动”，启动游戏后无反应

控制台窗口停留在 `Waiting for a '...' process to start ...`，在启动器中打开游戏后无任何输出变化：

- **排查客户端匹配**：检查所选的客户端与实际运行的游戏是否一致。例如国服《原神》主程序为 `YuanShen.exe`，国际服为 `GenshinImpact.exe`。若在注入器中选错渠道，注入器将无法监听目标进程。详细对照请参考 [判断客户端类型](/zh_cn/Tutorial/check-your-client)。
- **检查执行权限**：若游戏启动器或游戏主程序启用了“以管理员身份运行”，而注入器以普通用户权限运行，注入器将因权限不足无法挂载目标进程。尝试右键点击 HoYoShade 启动器并选择“以管理员身份运行”。
- **安全软件静默拦截**：部分防护软件会在不弹窗的情况下拦截内存注入 API。请参考 [杀毒软件排除设置](/zh_cn/Tutorial/antivirus) 为相关目录配置排除项。

## 2. 游戏启动后立即崩溃、闪退或弹出 D3D 错误

游戏打开时瞬间闪退、黑屏关闭或提示 Direct3D 设备丢失：

- **第三方游戏覆层冲突**：ReShade 需要接管 DirectX 的交换链与渲染调用。若后台同时存在其他挂钩工具，极易发生接口竞争：
  - **RivaTuner Statistics Server (RTSS)**：将游戏的 Application Detection Level 设为 `None`，或开启 Custom Direct3D Support。
  - **GeForce Experience / NVIDIA App**：在设置中暂时关闭“游戏内覆盖”。
  - **Discord / Steam / 游戏加加**：关闭对应软件的游戏内悬浮窗与状态监测覆层。
- **显卡驱动异常**：过旧的显卡驱动可能缺少部分 DirectX 11/12 渲染扩展指令，建议更新至显卡厂商最新发布的稳定版驱动。
- **着色器文件损坏**：若自行添加了外部着色器，语法错误可能导致编译异常。可尝试暂时清空自定义着色器，恢复为默认自带的 `reshade-shaders`。

## 3. 进入游戏后按 Home 键无法呼出配置菜单

游戏画面正常渲染，但无法打开 ReShade 设置界面：

- **确认键盘组合键映射**：许多笔记本电脑或 87 键紧凑型键盘没有独立的 <kbd>Home</kbd> 物理按键，通常需要配合 <kbd>Fn</kbd> 键输入（如 <kbd>Fn</kbd> + <kbd>Home</kbd> 或 <kbd>Fn</kbd> + <kbd>←</kbd>）。
- **确认 `ReShade.ini` 所在路径**：`ReShade.ini` 必须放置在包含游戏可执行文件的目录中，而非启动器外层目录。若该文件未就位，ReShade 将无法读取快捷键绑定。
- **自定义呼出快捷键**：若按键冲突，可在记事本中打开游戏目录下的 `ReShade.ini`，搜索 `KeyOverlay=` 并将键码更改为其他按键（例如将 `KeyOverlay=36,0,0,0` 改为其他键值）。

## 4. 游戏版本更新后如何恢复使用？

米哈游游戏客户端在常规热更新或大版本换代后：

- 理论上 HoYoShade 无需等待重新适配，仍可直接注入。
- 若更新后无法呼出，请检查游戏目录中的 `ReShade.ini` 是否在更新过程中被官方启动器清理。若丢失，重新从 HoYoShade 目录复制一份即可。

## 5. 景深 (DOF) 等深度缓冲区特效不生效

- 为防止在线网络游戏中利用深度通道实现透视外挂，通用 ReShade 会在检测到网络通信或特定多玩家场景时关闭高精度深度缓冲区访问。
- HoYoShade 附带的调色预设主要基于颜色校正、曲度调光、色调映射（Tonemap）与锐化算法，无需深度缓冲即可稳定生效。
